# Cyber Security Toolkit

## Description
The Cyber Security Toolkit is a Python-based application that combines multiple cybersecurity tools into a single project.

## Features
- Password Manager
- File Integrity Checker
- Network Scanner
- OSINT Toolkit
- Secure Data Protector

## Technologies Used
- Python
- hashlib
- socket
- os
- json

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:
   python main.py
